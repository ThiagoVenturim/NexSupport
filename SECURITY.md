# Security policy

## Reporting a vulnerability

Do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/ThiagoVenturim/Support_Intelligence_Engine/security/advisories/new)
(Security tab, "Report a vulnerability").

Include what is affected, how to reproduce it and the impact you expect. You will
get an answer within 7 days. Please give a reasonable time to ship a fix before
disclosing it publicly.

## Supported versions

Only the latest release on `main` receives security fixes.
